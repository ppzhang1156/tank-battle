# 坦克大战 Battle City

一个使用原生 HTML5 Canvas + JavaScript 编写的经典坦克大战小游戏，单文件即可运行。

## 玩法

- **移动**：方向键 或 `WASD`
- **开火**：空格 或 `J`
- **暂停**：`P`
- **开始/重新开始**：`Enter` 或点击按钮

## 目标

保护基地（金色鹰徽），消灭每一波敌方坦克。基地被摧毁或生命耗尽即游戏结束。

## 特性

- 波次递增，敌人越来越强（更快、更多、部分双倍血量）
- 可摧毁的砖墙、可反弹子弹的钢墙、藏身的树林
- 道具掉落：加命、护盾、加速、威力增强、冰冻敌人
- 出生无敌护盾、子弹对撞、粒子爆炸特效
- 使用 Web Audio API 的 8-bit 风格音效
- 得分系统与生命显示

## 运行

直接用浏览器打开 `index.html` 即可，无需任何依赖或构建步骤。

也可以在线体验：<https://你的用户名.github.io/仓库名/>
